# Test saves

The `load-*` and `store-*` scenarios in `recomp/tests/scenario.py` start from saves that aren't published here
(saves hold a player's own game). Put your own here to run them:

- `fnvtest1.fos`: a save made just after character creation (Goodsprings at noon);
- `store.fos`: a save inside Goodsprings' general store, third person.
